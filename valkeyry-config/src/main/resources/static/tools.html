Upload .xlsx .csv .dmn files and convert them to JSON ready for the existing /tables/{name}/entries:batch endpoint.

Output shape

      
{
  "source": "xlsx" | "csv" | "dmn",
  "fileName": "<name>",
  "tables": [{
    "tableName": "...",
    "columns":   ["..."],
    "rows":      [{ "<col>": <value>, ... }]
  }]
}

      
Each tables[].rows[*] object can become the data field of an IngestRecordRequest when you POST to /api/v1/tenants/{tenant}/tables/{name}/entries.
